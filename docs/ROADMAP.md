# Дорожная карта — Dungeon Monsters

Версия: 0.1 · 2026-09-28
Каждый milestone заканчивается **играбельной сборкой**, независимым ревью и обновлением документации.
Промт реализации каждого milestone — `docs/prompts/milestones/M<N>_*.md`.
Оценки — в рабочих сессиях Claude (≈ 1 сессия = 2–4 часа активной работы), ориентировочно.

## Правила дорожной карты
- Порядок M0→M8 фиксирован (каждый опирается на предыдущий). Фазы B/C можно переставлять ADR-ом.
- Перед стартом milestone Claude **уточняет его промт** по итогам предыдущего (раздел «Уточнения» внизу файла промта).
- Milestone закрыт, только если: DoD выполнен, CI зелёный, ревью без открытых blocker/major, `STATUS.md` обновлён,
  тег `v0.<N>.0` поставлен (M0 → `v0.0.0`) **на squash-коммит в `main` после merge**.
- Риски и их отслеживание — `docs/RISKS.md`.

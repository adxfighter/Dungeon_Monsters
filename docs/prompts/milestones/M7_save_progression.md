# M7 — Сохранения и прогрессия

> Перед стартом: `docs/prompts/00_session_start.md`. Опирается на M6.

## Цель
Надёжные сохранения с миграциями и мягкий roguelite-прогресс между забегами.

## Контекст
GDD §3 (смерть), §4.8; ARCHITECTURE §9.

## Задачи
1. **SaveData** (Zod-схема): `saveVersion`, `meta` (открытые рецепты, бестиарий, мастерство повара, снаряжение,
   кристаллы, флаги сюжета, настройки), `run` (этаж, seed, отряд HP, рюкзак, бафы) — опционально.
2. **Storage-адаптер** (`platform/storage`): IndexedDB через idb-keyval, 3 слота + автосейв; фолбэк localStorage;
   защита от порчи (запись во временный ключ → переключение), экспорт/импорт сейва строкой (для отладки).
3. **Миграции** `core/save/migrations`: реестр, тест «v1 фикстура → текущая версия».
4. **Автосохранение**: вход на привал, конец этажа, выход в хаб, `visibilitychange: hidden` / `pagehide`.
5. **Смерть**: катсцена выноса, потеря рюкзака и бафов, сохранение мета-прогресса, экран итогов забега.
6. **Мастерство повара**: XP за блюда (больше за новые и ★4+), уровни открывают слоты/методы (данные).
7. **Снаряжение**: 3 слота на героя, покупка/улучшение за кристаллы в хабе (кузница-заглушка → простой UI).
8. **Меню**: главное (продолжить/новая игра/настройки), пауза, настройки (громкость, вибро, шейк камеры,
   качество графики, упрощённые мини-игры, язык).

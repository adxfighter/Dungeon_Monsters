# M8 — Страж, полировка и вертикальный срез (MVP)

> Перед стартом: `docs/prompts/00_session_start.md`. Опирается на M0–M7. Итог — MVP для плейтеста.

## Цель
Завершить Ярус I стражем, добавить звук и полировку, чтобы срез ощущался как настоящая игра.

## Контекст
GDD §5–§9; STORY §4 (Акт I, финал яруса).

## Задачи
1. **Страж Жабоцарь Бульк**: арена, 2 фазы (фаза 2 при 50% HP — «голодное безумие», глотает мелких монстров
   и лечится → игрок может помешать), 4 атаки с телеграфами, уникальная разделка, пир-катсцена с Утробой,
   «вздыхающей» и открывающей путь.
2. **Аудио** (`platform/audio`, Howler): unlock по первому тапу, музыка (лагерь, исследование, бой, босс —
   кроссфейд), SFX боя, **ASMR готовки** (шкварчание, нарезка, бульканье), UI-клики. Источники CC0 → `docs/ASSETS.md`.
3. **Полировка**: крупные планы блюд, переходы сцен, анимации UI, экран загрузки с подсказками, иконка/splash.
4. **Туториал** — проверка, что новичок без объяснений проходит Пролог (Playwright-сценарий + плейтест).
5. **i18n**: полный en-перевод, переключение языка.
6. **PWA**: service worker (vite-plugin-pwa), офлайн после первой загрузки, установка на домашний экран.
7. **Perf-проход**: профили качества low/medium/high с автоопределением, замер на устройстве пользователя.
8. **Плейтест-пакет**: `docs/PLAYTEST.md` — инструкция для тестеров, анкета (5 вопросов), сбор фидбека;
   итоги → бэклог и RISKS.

## DoD (= MVP)
- [ ] Ярус I (Пролог + 3 этажа + страж) проходится целиком, без блокеров, на Android mid-range ≥ 30 FPS.
- [ ] Офлайн-работа и установка PWA.
- [ ] Регрессионный e2e зелёный. Ревью APPROVE (полное ревью всего среза, не только diff).
- [ ] Документация полная, CHANGELOG релиза, тег `v0.8.0` / `mvp`.
- [ ] Ретроспектива в `docs/DECISIONS_LOG.md` и пересмотр ROADMAP фаз B/C.

# M4 — Готовка (сердце игры)

> Перед стартом: `docs/prompts/00_session_start.md`. Опирается на M3. Самый важный milestone для «фана» —
> закладывать время на итерации ощущений.

## Цель
Привал у костра, где из добычи готовят блюда через короткие тач-мини-игры; блюда лечат, дают бафы и вызывают
реакции героев.

## Контекст
GDD §2 (столп 3), §4.5; STORY §2 (Матушка Орзу, реакции), §7.

## Задачи
0. **Ограничение этапа**: отряд появляется в M6. В M4 у костра только Тави; «бонус повара» = уровень мастерства
   (заглушка = 1), реакции — только Тави, но система реакций сразу рассчитана на N героев.
1. **Схемы**: `RecipeDef {id, nameKey, slots: TagRequirement[], method, resultDish}`, `DishDef {id, heal,
   buffs[], flavorProfile, presentationKey}`, `BuffDef {id, stat/flag, value, duration: floors}`,
   `MethodDef {id, minigameId, params}`.
2. **12 рецептов** Яруса I + правила «эксперимента» (блюдо без рецепта: подбор ближайшего по тегам с
   пониженным качеством; удачный эксперимент → открывает рецепт).
3. **Формула качества** (core, чистая функция, тесты): среднее качество ингредиентов × оценка мини-игр ×
   бонус повара × совпадение вкусов → ★1–★5. Параметры в `balance.ts`.
4. **Сцена привала** (`app/scenes/Camp`): костёр (частицы, мерцающий свет), места для героев вокруг, тёплая палитра,
   смена музыки (заглушка до M8).
5. **UI готовки**: выбор рецепта (или «эксперимент») → перетаскивание ингредиентов в слоты → мини-игры:
   - **Нарезка** — свайпы по ингредиенту в ритм;
   - **Жарка** — удержание пальцем для поддержания температуры в зелёной зоне;
   - **Варка** — круговые движения для помешивания с постоянной скоростью;
   - **Приправа** — тап в момент попадания маркера в зону.
   Каждая 5–10 с, оценка в core, опция «упрощённые мини-игры».
   Сделать **два варианта** управления для жарки и выбрать по ощущению (риск R3), решение в DECISIONS_LOG.
6. **Подача**: крупный план блюда (пар — частицы, блеск — specular-спрайт), название, звёзды, бафы.
7. **Реакции героев**: пул реплик по тегам вкуса/качества в `content/dialogue/reactions.ts`, бабблы над героями.
8. **Бафы** применяются к следующему этажу (≤ 2 одновременно) и отображаются в HUD.
9. **Дневник рецептов** (UI): открытые/неизвестные (силуэт) рецепты, лучшие результаты.

## [Unreleased]
### Добавлено (M1)
- Героиня Тави (чиби из примитивов: большие глаза, чёлка, хвостик, анимация шага и покачивания) ходит по тестовой
  комнате из тайлов: стены, колонны, узкие коридоры, светящиеся грибы.
- Плавающий виртуальный джойстик в левой половине экрана (мёртвая зона 10%, второй палец не мешает);
  на компьютере — WASD/стрелки.
- Камера сверху-сзади с плавным следованием и упреждением по направлению движения.
- Экран-объяснение, если браузер не поддерживает WebGL2 (ru/en); игра ставится на паузу при сворачивании.
- Тестовая сцена M0 теперь по адресу `?demo=1`.

## [0.0.0] — 2026-09-28 · M0 «Фундамент»
### Добавлено
- Проектная документация: GDD, сценарий, архитектура, дорожная карта, правила разработки.
- Тестовая аниме-сцена: пол, три примитива и чиби-болванка с cel-shading (3 ступени тени), rim-светом и чёрным контуром.
- Сборка открывается на телефоне по https://adxfighter.github.io/Dungeon_Monsters/ (портрет, полноэкранный режим,
  можно добавить на главный экран).
- Dev-оверлей `?debug=1` (FPS, draw calls, треугольники, pixelRatio) и `?pr=1` (pixelRatio 1).

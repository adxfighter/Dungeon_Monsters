# ADR-0004: Добыча в M3 — команды UI → core, модальная пауза, качество ★ как чистая функция

- Статус: **Принято**
- Дата: 2026-09-29
- Контекст решений пользователя: элемент добивания — смена оружия кнопкой (клинок ↔ факел); ингредиенты — 1–2 части
  с каждого монстра + 5 растений (старт M3).

## Контекст
M3 связывает бой и готовку: способ убийства и разделка определяют качество ингредиента. Нужно было решить, где живёт
логика (core или UI), как UI сообщает результат мини-игры, что происходит с боем, пока открыта мини-игра или
рюкзак, и как хранить бестиарий до системы сохранений (M7).

## Рассмотренные варианты
| Вопрос | Вариант | + | − |
|---|---|---|---|
| Как UI передаёт «разделать / собрать / выбросить» | **Команды `Game.butcher/gather/discard`, применяются на шаге** | детерминизм, core проверяет всё сам (досягаемость, состояние героини) | чуть больше кода |
| | Кнопка в `InputState` (`Buttons.Action`) | просто | результат мини-игры (★ по частям) в кнопку не помещается; было в PR #15, убрано |
| Бой во время мини-игры/рюкзака | **Пауза: main не шагает симуляцию** | честно на тач-экране, туши не гниют | игрок не видит «живого» боя |
| | Бой идёт | реалистично | за 2–4 с свайпов героиню убьют |
| Качество ★ | **Чистые функции core (`ingredientStars`, `scoreSwipe`, `tapStep`)** | тесты без DOM, числа в `BALANCE` | — |
| Бестиарий до M7 | **localStorage `dm.bestiary.v1`** | работает сразу, миграция позже | не в общем сохранении |

## Решение
- **Туша** — сущность `Carrion {monsterId, killElement, overkillRatio, left}` (M2 + M3). Качество части:
  `★ = clamp(★ разреза + IngredientDef.kill[элемент] − (перебор > 50 % max HP ? 1 : 0), 1, 3)`; пропуск = ★1.
- **Мини-игра** (`ui/butchery/ButcherBoard`) оценивает свайп/тапы функциями `core/loot/cut.ts`, результат — команда
  `Game.butcher(туша, ★ по частям, пропуск)`; не влезшее в рюкзак остаётся на туше (`Carrion.left`).
- **Контекстная кнопка** — селектор `Game.interaction` (butcher / gather / full / null) с теми же проверками, что и
  команды, поэтому кнопка не обещает того, чего core не сделает.
- **Модальные окна** (доска разделки, рюкзак/бестиарий) ставят бой на паузу; выброс из рюкзака применяется
  `Game.applyCommands()` без шага симуляции.
- **Победа в арене** ждёт туши, из которых ещё что-то влезет в рюкзак (`worthButchering`).
- **Бестиарий** — `core/bestiary.ts` (`recordBestiary` по событиям, `bestKillElement`, `weaknesses`), хранение —
  `platform/bestiaryStore`.

## Последствия
- Новые взаимодействия (готовка в M4, сундуки, NPC) — тем же путём: селектор для UI + команда в core.
- Рюкзак и бестиарий не сохраняются в файл сохранения до M7; при его появлении — `saveVersion` и миграция из
  `dm.bestiary.v1`.
- Во время модальных окон нельзя «подсмотреть» телеграфы — это осознанный компромисс ради тач-управления.

# ADR-0002: Оригинальная IP, вдохновлённая Dungeon Meshi

- Статус: **Принято**
- Дата: 2026-09-28

## Контекст
Пользователь хочет игру «на основе Dungeon Meshi». Права на тайтл принадлежат Ryōko Kui / KADOKAWA.

## Решение
Берём **тему и жанровую идею** (готовка монстров в подземелье, экосистема, отряд авантюристов),
но мир, персонажей, сюжет, монстров и визуал создаём **свои**. Подробности — `docs/LEGAL.md`, мир — `docs/STORY.md`.

## Последствия
- Игру можно публиковать в сторах и монетизировать.
- Нужна дисциплина: IP-проверка в каждом ревью.
- Если пользователь выберет фан-проект с оригинальными персонажами — новый ADR, отдельная непубликуемая сборка.
